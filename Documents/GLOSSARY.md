# Glossary

- **ADB:** Android Debug Bridge; the v1 USB transport prerequisite.
- **A/V sync:** alignment of audio samples and video presentation timestamps.
- **CamLink Host:** native Windows media/session process.
- **DPAPI:** Windows API used to protect local secrets for the current user.
- **IDR:** H.264 keyframe suitable for decoder recovery.
- **mDNS:** local multicast discovery protocol.
- **MF:** Media Foundation, the Windows media framework.
- **OBS plugin:** native extension that integrates CamLink media with OBS.
- **Opus:** low-latency audio codec used for the OBS audio path.
- **Trusted peer:** phone or PC with a mutually established pairing key.
