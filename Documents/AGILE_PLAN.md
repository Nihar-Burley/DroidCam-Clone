# Agile Plan and Roadmap

## Solo one-month MVP plan

| Week | Outcome | Story points |
|---|---|---:|
| 1 | Android capture/encode, shared protocol, ADB proof | 18 |
| 2 | TLS Wi-Fi pairing/discovery, Windows Host decode | 20 |
| 3 | virtual camera, OBS source, companion UI, reconnect | 22 |
| 4 | installer/signing, matrix tests, accessibility, docs, release candidate | 18 |

Epics: trusted pairing; Android media; transport/session; Windows output; OBS; installer/release; quality/security. The product owner prioritizes a stable 1080p30 USB flow over any deferred feature. Daily solo review: unblock, measure, trim scope; weekly demo uses a fresh machine and baseline phone. A public release is contingent on quality gates, not calendar date.

Post-v1: virtual microphone, 1440p/4K, advanced manual controls, screen mirroring, multi-phone/AI, Windows ARM64, iOS/macOS/Linux, then remote/cloud only after separate architecture and security approval.
