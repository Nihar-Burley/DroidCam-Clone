# Contributing

Read [CODING_STANDARDS.md](CODING_STANDARDS.md), [GIT_WORKFLOW.md](GIT_WORKFLOW.md), and [SECURITY.md](SECURITY.md) before contributing. Open an issue for significant changes; keep pull requests narrow, tested, documented, and free of generated artifacts. Report security vulnerabilities privately to the maintainers rather than public issues until a fix is available.

Contributors grant work under Apache-2.0 and must confirm third-party dependencies are compatible with the product’s licensing, security, and offline-first requirements. Changes that collect data, add cloud services, add a driver, or alter pairing require an approved ADR.
