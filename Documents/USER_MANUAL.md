# User Manual

## First connection

1. Install the signed Windows package and Android APK from the same release.
2. For USB, install Android platform-tools, enable Developer Options and USB debugging, then authorize the PC fingerprint on the phone. For Wi-Fi, place both devices on the same private LAN.
3. Open CamLink on both devices, select **Pair device**, scan the Windows QR code, and confirm the displayed names on both screens.
4. Choose USB or Wi-Fi, select a profile, and start. Select **CamLink Virtual Camera** in a meeting app, or add the CamLink source in OBS.

## Daily use and diagnostics

Trusted devices reconnect automatically. The quality indicator reports stable, adapting, reconnecting, or disconnected. Use lower resolution/FPS before moving closer to Wi-Fi. If pairing fails, verify both releases match, the firewall allows private networks, and USB debugging is authorized. Export diagnostics only after reviewing its contents; it includes technical state but not recorded media.

## Safety and accessibility

Revoke a PC from the phone or a phone from Windows when disposing of either device. Use keyboard navigation in Windows; all primary controls have accessible names and visible focus. The app does not operate while Android camera permission is denied or the foreground-service notification is dismissed.
