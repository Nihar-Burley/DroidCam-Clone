# Roadmap

## v1 — Local camera MVP

Android 10+, Windows x64, ADB USB, same-LAN encrypted Wi-Fi, trusted QR pairing, 1080p profiles, front/rear camera, virtual camera, native OBS video/audio source, diagnostics, signed installer, and public GitHub release.

## v1.1 — Audio and quality

Virtual microphone subject to driver certification, improved manual controls, broader app compatibility, 1440p where performance data supports it, and managed beta update channels.

## v2+ — Expansion

4K/HDR, recording, screen sharing, multi-phone switching, AI effects, Windows ARM64, iOS/macOS/Linux, and a plugin SDK. Remote camera/cloud capability is explicitly last: it requires accounts or a robust alternative identity model, relay operations, abuse controls, and a new privacy/security review.
